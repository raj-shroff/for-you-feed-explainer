# Why this video?

A five-screen, animated classroom walkthrough of how TikTok chooses videos for the For You feed. Built for a community college audience in plain language.

## Run it

Double-click `index.html` to open it in a modern browser. Keep `styles.css`, `app.js`, and the `assets` folder alongside it. No installation, build, account, API, or internet connection is needed.

- **Next / Back** move between the five screens.
- **Dots** jump directly to a screen.
- **Replay step** resets the current screen and its interactions.
- **Left / right arrow keys** navigate; **Home** returns to the intro.
- **Motion: off** makes state changes immediate. The operating system's reduced-motion preference is also respected.
- **Start again** returns to the beginning.

Use the buttons inside screens 2–5 to watch, like, skip, sort, and try a new topic. Your early choices affect later screens. The final screen lets you select topics and change a sample feed, with a visible history of your recent choices. Replay step resets the current exercise; Start again clears everything. The example is scripted for teaching, not a live recommendation engine.

## Five screens

1. What this explains: how TikTok picks the next video.
2. Your actions leave clues.
3. Clues help compare possible videos.
4. Variety and eligibility also shape the feed.
5. A hands-on feed that changes as you watch, like, or skip different topics.

## Research note

The walkthrough demonstrates how choices can influence later recommendations. Its sorting rules and immediate updates are illustrative. The research catalog records the evidence and limitations; technical background has been removed from the on-screen lesson.
